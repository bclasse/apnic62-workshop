# Startup configurations

Per-lab SR Linux startup configs in CLI `set` format for containerlab.

## Layout

| Directory | Purpose |
|-----------|---------|
| `base/` | Shared underlay (interfaces + IS-IS) |
| `lab1-start/` … `lab5-start/` | Per-lab starting state |
| `active/` | Runtime copy used by `apnic62-wan.clab.yml` (generated by deploy script) |

## Regenerate

```powershell
# Windows
.\scripts\generate-configs.ps1

# Linux / macOS (requires Python 3)
python3 scripts/generate-configs.py
```

After regenerating, redeploy with `./scripts/deploy-lab.sh <N>`.
